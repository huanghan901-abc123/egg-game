# 《小蛋的单词冒险》数据结构规范

**版本：** V1.0  
**最后更新：** 2026-08-04  
**文档目的：** 规定单词表格式、存档数据结构，确保开发和数据准备统一

---

## 一、单词表Excel格式规范

### 1.1 文件信息
- **文件名：** `grade4_words.xlsx`
- **存放位置：** `data/` 文件夹
- **说明：** 包含两张地图的全部单词数据

### 1.2 Sheet结构
Excel文件包含 **2个Sheet**：

| Sheet名称 | 内容 | 单词数 |
|-----------|------|--------|
| desert | 沙漠地图单词（四年级上册） | 150个 |
| forest | 森林地图单词（四年级下册） | 150个 |

### 1.3 列结构（每个Sheet都一样）

| 列号 | 列名 | 类型 | 说明 | 示例 |
|------|------|------|------|------|
| A | id | 数字 | 单词编号，从1开始连续编号 | 1 |
| B | english | 文本 | 英文单词 | apple |
| C | chinese | 文本 | 中文意思 | 苹果 |
| D | level | 数字 | 难度等级（1-5，暂时都填1） | 1 |
| E | unit | 数字 | 所属单元（暂时都填1） | 1 |

### 1.4 关卡分配规则
- 第1关：单词1~10
- 第2关：单词11~20
- 第3关：单词21~30
- ...以此类推
- 第15关：单词141~150
- 第16关（复习关）：从全部150个单词中随机抽10个

### 1.5 Excel示例

**Sheet: desert**

| id | english | chinese | level | unit |
|----|---------|---------|-------|------|
| 1 | apple | 苹果 | 1 | 1 |
| 2 | banana | 香蕉 | 1 | 1 |
| 3 | cat | 猫 | 1 | 1 |
| ... | ... | ... | ... | ... |
| 150 | zoo | 动物园 | 1 | 1 |

## 二、LocalStorage 存档数据结构

### 2.1 存档总览
所有数据保存在浏览器 LocalStorage 中，Key 为 `eggy_save_data`，值为 JSON 字符串。

### 2.3 字段说明

#### 基础信息
| 字段 | 类型 | 说明 |
|------|------|------|
| version | string | 存档版本号，方便以后升级 |
| username | string | 用户名 |
| password | string | 密码（明文，本地存储无所谓） |
| createTime | number | 创建时间戳 |
| lastPlayTime | number | 最后游戏时间戳 |

#### 货币
| 字段 | 类型 | 说明 |
|------|------|------|
| stars | number | 星星总数 |
| diamonds | number | 钻石总数 |
| airCount | number | 累计抽到空气的次数 |

#### 皮肤
| 字段 | 类型 | 说明 |
|------|------|------|
| currentSkin | string | 当前装备皮肤ID |
| unlockedSkins | array | 已解锁皮肤ID列表 |

#### 每日任务
| 字段 | 类型 | 说明 |
|------|------|------|
| dailyTask.date | string | 日期（YYYY-MM-DD） |
| dailyTask.threeStarCount | number | 今日获得三星的关卡数 |
| dailyTask.diamondClaimed | boolean | 今日钻石是否已领取 |

#### 地图数据
| 字段 | 类型 | 说明 |
|------|------|------|
| maps[mapId].unlocked | boolean | 地图是否解锁 |
| maps[mapId].totalScore | number | 地图总分 |
| maps[mapId].totalStars | number | 地图总星数 |
| maps[mapId].diamondClaimed | boolean | 通关钻石是否已领取 |
| maps[mapId].levels[levelId].bestScore | number | 关卡最高分 |
| maps[mapId].levels[levelId].stars | number | 关卡星级（0-3或5） |
| maps[mapId].levels[levelId].unlocked | boolean | 关卡是否解锁 |
