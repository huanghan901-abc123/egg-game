# 《小蛋的单词冒险》美术资源规范

**版本：** V1.0  
**最后更新：** 2026-08-04  
**文档目的：** 规定所有图片资源的命名、尺寸、用途，确保开发时能正确引用

---

## 一、总体规范

### 1.1 图片格式
- 统一使用 **PNG** 格式
- 背景图：JPG也可以，但优先PNG
- 角色/UI：必须PNG透明背景

### 1.2 命名规则
- 全部小写英文 + 下划线
- 格式：`类别_名称.png`
- 示例：`desert_01_worm_cave.png`、`egg_default.png`
